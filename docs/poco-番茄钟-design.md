# Poco · 番茄钟产品设计文档

---

## 1. 定位

一个常驻 macOS 菜单栏、**简约优雅**的番茄钟，帮助规律学习与工作。

设计隐喻：**菜单栏倒计时是"甜点"，主窗口是"主菜"**。
- 菜单栏：全天常驻，余光可见剩余时间，最克制。
- 主窗口：真正的操作界面，承载完整交互。
- 两者共享同一计时状态，**实时同步**。

只做 macOS，不考虑跨平台。

**产品哲学**：保持极简。不做任务管理、统计报表、云同步、桌面浮窗这类会侵蚀"菜单栏极简番茄钟"定位的功能——番茄钟的价值在克制，不在堆功能。

---

## 2. 形态与窗口行为

| 项 | 决定 |
|---|---|
| 菜单栏 | 常驻单槽位：未运行（待开始/结束）显示番茄图标；运行显示 `MM:SS` 倒计时文本、暂停 `⏸ MM:SS`，余光可见 |
| 双击菜单栏 | 唤出 / 聚焦主窗口（单击不响应，避免误触） |
| 右键菜单栏 | 弹菜单：显示主窗口 / 设置 / 开始·暂停 / 重置 / 跳过 / 退出 |
| 主窗口 | 主操作界面，纯数字极简，浅/深双主题（默认浅色，设置内切换） |
| 关闭主窗口 | 隐藏到菜单栏，**不退出**应用 |
| 退出应用 | 通过菜单栏右键菜单的「退出 Poco」 |
| 状态同步 | 菜单栏文本与主窗口倒计时来自同一计时源，实时一致 |

---

## 3. 核心轮回

- 阶段类型：**专注 / 短休 / 大休**
- 默认时长：**专注 25 分钟 / 短休 5 分钟 / 大休 15 分钟**（设置里可改三个时长）
- 轮回规则：每完成 **4 个专注** → 进入 **1 次大休** → 计数归零，重新开始
- 每组轮数 **固定为 4**

阶段序列示意：
```
专注 → 短休 → 专注 → 短休 → 专注 → 短休 → 专注 → 大休 →（循环）
  1           2           3           4
```

主窗口用 **4 颗圆点**表示当前处于本组第几个专注轮。

---

## 4. 节奏：手动推进

- 一个阶段倒计时归零后，**不自动进入下一阶段**。
- 阶段结束时触发提醒：
  - **系统原生通知**（如「专注结束，该休息了」）
  - **程序坞（Dock）图标跳动**
- 用户手动点击「开始」后，才进入下一阶段并开始计时。

---

## 5. 主窗口（纯数字极简）

布局自上而下：
1. **标题栏**：macOS 红黄绿三色按钮 + 右上角设置齿轮 ⚙
2. **阶段标签**：大写字距拉开的小标签，「专注 / 短休 / 大休」
   - 配色语义：**暖橙 = 专注，青色 = 休息**（短休/大休）
3. **进度环**：满环 → 运行消减 → 结束归零，含刻度/光晕 + 呼吸动画
4. **大号倒计时**：细体、等宽数字、视觉中心
5. **轮次进度**：4 颗圆点，已完成/进行中点亮为暖橙
6. **控制区**（三键）：
   - **重置**：当前阶段回到满时长（暂停态）
   - **开始 · 暂停**（主按钮）：启动 / 暂停当前阶段倒计时
   - **跳过**：立即结束当前阶段，进入下一阶段的待开始态（**不弹通知**，因为是用户主动操作）

窗口尺寸：小巧（宽约 280px，圆角卡片感）。

---

## 6. 设置

- 可调项：**专注时长 / 短休时长 / 大休时长**（分钟，范围 1–60）
- 入口：主窗口右上角齿轮，滑入同一窗口
- 默认值：25 / 5 / 15
- 主题切换：自定义分段控件，浅色 / 深色，不跟随系统

---

## 7. 交互状态机（计时器）

每个阶段是一个倒计时，状态：

- **待开始（Ready）**：显示该阶段满时长，未走表。等待「开始」。
- **运行（Running）**：倒计时递减；菜单栏同步。
- **暂停（Paused）**：冻结当前剩余时间。
- **结束（Finished）**：归零，触发提醒（系统通知 + Dock 图标跳动），停在该阶段，等待用户「开始」推进到下一阶段。

按钮对状态的作用：
- 开始/暂停：Ready/Paused → Running；Running → Paused
- 重置：任意 → 当前阶段 Ready
- 跳过：任意 → 下一阶段 Ready（不提醒）
- 阶段自然 Finished → 提醒 → 用户「开始」→ 下一阶段 Running

---

## 8. 数据与持久化

- **只持久化设置**（三个自定义时长 + 主题）。存入 `UserDefaults`。
- **不持久化计时进度**：应用退出后计时不保留，重开从第一个专注阶段的 Ready 态开始。

---

## 9. 功能清单

- [x] 菜单栏常驻倒计时（单槽位图标⇄文本）+ 双击唤出主窗口 + 右键菜单
- [x] 主窗口（进度环 + 呼吸动画 + 纯数字极简，浅/深双主题）
- [x] 专注/短休/大休轮回，4 轮一大休
- [x] 手动推进 + 系统通知 + Dock 图标跳动
- [x] 开始 / 暂停 / 重置 / 跳过
- [x] 自定义三个时长（设置）
- [x] 关闭主窗口隐藏到菜单栏，菜单栏菜单可退出
- [x] 浅/深双主题（默认浅色，设置内切换，持久化）

**有意不做**（见上文「产品哲学」）：任务管理 / 统计报表 / 云同步 / 桌面浮窗。
