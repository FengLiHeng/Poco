# 菜单栏倒计时文本 · 设计文档

日期：2026-06-10
状态：已实现并迭代为方案 B（单槽位，见文末「迭代记录」）；方案 A 部分保留为历史决策

## 背景与目标

设计文档（2026-06-09）要求菜单栏显示动态倒计时文本，当前用 `TrayIcon.ToolTipText` 折中（需悬停才可见）。经核实，Avalonia `TrayIcon` 只暴露 `Icon` / `ToolTipText` / `Menu` / `Command`，无法设置 macOS `NSStatusItem` 的标题文本，纯托管做不到，需借原生层。

目标：菜单栏直接可见倒计时，与主窗口共享同一计时源，实时同步。

## 方案选型

- **方案 A（采用）：双槽位** —— 保留现有 Avalonia TrayIcon（图标 + 菜单），dylib 里另建一个纯文本 `NSStatusItem`。改动最小、风险低，`dotnet run` 下即可用。
- 方案 B（备选升级）：托盘整体搬进原生层，图标 + 文字一体单槽位，菜单回调桥接成本高。A 的 Swift 代码可复用，体验不满意时再升级。
- 方案 C（否决）：把倒计时渲染成图标图片，文字观感差、可能闪烁，与产品气质不符。

## 显示策略（已确认）

| 计时状态 | 菜单栏文本 |
|---|---|
| Running | `24:31` |
| Paused | `⏸ 24:31` |
| Ready / Finished | 隐藏（`isVisible = false`，只剩番茄图标槽位） |

## 设计

### 1. 原生层（Swift，编进现有 libPocoNotify.dylib）

- `poco_tray_set_text(const char* utf8)`：首次调用时在主队列创建变长 `NSStatusItem`；非空字符串 → 设置文本并 `isVisible = true`；NULL/空串 → `isVisible = false`（隐藏不销毁，避免槽位左右跳动）。
- 文本用 `attributedTitle` + `NSFont.monospacedDigitSystemFont`（等宽数字），跳秒时宽度不抖（对应主窗口 `+tnum` 的同款处理）。深浅色菜单栏由系统自动适配。
- 点击文字项 → 回调唤出主窗口（机制同通知点击回调）。

### 2. 托管层（C#）

- 新增 `Platform/MacTrayText.cs`（仿 `MacNotifier` 形态）：`TryInit()` + `SetText(string?)`，P/Invoke 进 dylib；非 macOS、dylib 缺失时静默 no-op。NSStatusItem 不需要 bundle 身份，开发期 `dotnet run` 即可用。
- `MainWindowViewModel` 新增派生属性 `TrayText`：Running → `"MM:SS"`，Paused → `"⏸ MM:SS"`，Ready/Finished → `null`。在 `OnRemainingSecondsChanged` 与 `RaiseDerived` 中广播（与 `TrayTooltip` 同管线）。
- `App.axaml.cs` 现有 `PropertyChanged` 监听处：`TrayText` 变更 → `MacTrayText.SetText`。现有 TrayIcon 的图标、菜单、ToolTip 不动，ToolTip 兼作非 macOS 回退。

### 3. 错误处理与边界

- dylib 加载/初始化失败 → 所有调用 no-op，退化为现状（仅 ToolTip），不影响计时。
- 系统睡眠唤醒后首个 tick 按墙钟刷新 `RemainingSeconds`，菜单栏文本自动跟上。
- 跳过/重置回 Ready → 文本自动隐藏（由状态映射保证）。

### 4. 测试与打包

- `TrayText` 状态→文本映射加 xUnit 单测（驱动 VM 状态机验证三种输出）。
- 原生部分手测：`dotnet run` 与打包 `.app` 各验一遍（运行/暂停/跳过/主题切换/点击文字项唤窗）。
- `scripts/package-mac.sh` 已编译 dylib；若拆新 Swift 文件，编译命令多列一个源文件即可。

## 迭代记录：合并为单槽位（方案 B，2026-06-10 同日）

方案 A 验证可用后，按产品反馈合并为**单槽位**：

- **形态**：同一个 `NSStatusItem`——未运行（Ready/Finished）显示番茄图标（18×18，由 .NET 把内嵌 `tomato.png` 解到临时文件传给原生层）；运行显示 `MM:SS`、暂停 `⏸ MM:SS`（沿用 `TrayTextFormat` 映射，逻辑层零改动）。
- **交互取舍**：双击 → 唤出主窗口；右键 → 弹原生 NSMenu（显示主窗口/设置/开始·暂停/重置/跳过/退出，命令 id 回调桥回 `App.OnNativeTrayCommand`）；**单击不响应**（避免误触）。
- **右键弹菜单实现**：平时不挂 `item.menu`（挂了任何点击都弹菜单），右键时临时挂上 → `button.performClick` → 弹完摘掉。
- **平台分支**：macOS 弃用 Avalonia TrayIcon（`App.SetupNativeTray`）；非 macOS 回退原 TrayIcon + NativeMenu（`App.SetupAvaloniaTray`），保留 Windows 演进路径。
- `Platform/MacTrayText.cs` 更名为 `Platform/MacTray.cs`（增加菜单/双击/图标/ToolTip 能力）。
