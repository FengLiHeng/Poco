# Poco · 番茄钟 产品设计文档

> 日期：2026-06-09
> 状态：设计已确认并实现。产品规则仍然有效；技术栈已于 2026-06-10 从 Avalonia 迁移为原生 Swift（见 [2026-06-10-swift原生重写-design.md](2026-06-10-swift原生重写-design.md)），文中 Avalonia 相关表述仅作历史记录
> 技术栈：~~Avalonia（.NET 跨平台），首发 macOS~~ → 原生 Swift（SwiftUI + AppKit），仅 macOS

---

## 1. 定位

一个常驻 macOS 菜单栏、**简约优雅**的番茄钟，帮助规律学习与工作。

设计隐喻：**菜单栏倒计时是"甜点"，主窗口是"主菜"**。
- 菜单栏：全天常驻，余光可见剩余时间，最克制。
- 主窗口：真正的操作界面，承载完整交互。
- 两者共享同一计时状态，**实时同步**。

只做 macOS，不考虑跨平台。

**产品哲学**：保持极简。不做任务管理、统计报表、云同步、桌面浮窗这类会侵蚀"菜单栏极简番茄钟"定位的功能——番茄钟的价值在克制，不在堆功能。

---

## 2. 形态与窗口行为

| 项 | 决定 |
|---|---|
| 菜单栏 | 常驻单槽位：未运行（待开始/结束）显示番茄图标；运行显示 `MM:SS` 倒计时文本、暂停 `⏸ MM:SS`，余光可见（实现时由 `🍅 24:32` 常驻文本迭代而来） |
| 双击菜单栏 | 唤出 / 聚焦主窗口（单击不响应，避免误触） |
| 右键菜单栏 | 弹菜单：显示主窗口 / 设置 / 开始·暂停 / 重置 / 跳过 / 退出 |
| 主窗口 | 主操作界面，纯数字极简，浅/深双主题（默认浅色，设置内切换；实现阶段由"仅深色"放宽） |
| 关闭主窗口 | 隐藏到菜单栏，**不退出**应用 |
| 退出应用 | 通过菜单栏右键菜单的「退出 Poco」 |
| 状态同步 | 菜单栏文本与主窗口倒计时来自同一计时源，实时一致 |

> 实现：原生 `NSStatusItem` 单槽位，图标⇄倒计时文本切换（`Tray/StatusItemController.swift`，状态→文本映射见 `Models/TrayTextFormat.swift`）。

## 3. 核心轮回

- 阶段类型：**专注 / 短休 / 大休**
- 默认时长：**专注 25 分钟 / 短休 5 分钟 / 大休 15 分钟**（设置里可改三个时长）
- 轮回规则：每完成 **4 个专注** → 进入 **1 次大休** → 计数归零，重新开始
- 每组轮数 **固定为 4**（v1 不进设置）

阶段序列示意：
```
专注 → 短休 → 专注 → 短休 → 专注 → 短休 → 专注 → 大休 →（循环）
  1           2           3           4
```

主窗口用 **4 颗圆点**表示当前处于本组第几个专注轮。

---

## 4. 节奏：手动推进

- 一个阶段倒计时归零后，**不自动进入下一阶段**。
- 阶段结束时触发提醒：
  - **系统原生通知**（如「专注结束，该休息了」）
  - **程序坞（Dock）图标跳动**
- 用户手动点击「开始」后，才进入下一阶段并开始计时。

> 不在 v1：提示音。以后若加，做成设置里的开关。

---

## 5. 主窗口（纯数字极简 · 深色）

视觉方向已确认为「方向一 · 纯数字极简」。

布局自上而下：
1. **标题栏**：macOS 红黄绿三色按钮 + 右上角设置齿轮 ⚙
2. **阶段标签**：大写字距拉开的小标签，「专注 / 短休 / 大休」
   - 配色语义：**暖橙 = 专注，青色 = 休息**（短休/大休）
3. **大号倒计时**：细体、等宽数字、视觉中心
4. **轮次进度**：4 颗圆点，已完成/进行中点亮为暖橙
5. **控制区**（三键）：
   - **重置**：当前阶段回到满时长（暂停态）
   - **开始 · 暂停**（主按钮）：启动 / 暂停当前阶段倒计时
   - **跳过**：立即结束当前阶段，进入下一阶段的"待开始 / 暂停"态（**不弹通知**，因为是用户主动操作）

窗口尺寸：小巧（参考宽约 280px，圆角卡片感）。

> 配色、字体、间距等细节由后续 UI 设计阶段细化；本文档锁定的是结构与交互，不锁死像素级视觉。

## 6. 设置

- 可调项：**专注时长 / 短休时长 / 大休时长**（分钟）
- 入口：主窗口右上角齿轮
- 默认值：25 / 5 / 15

---

## 7. 交互状态机（计时器）

每个阶段是一个倒计时，状态：

- **待开始（Idle/Ready）**：显示该阶段满时长，未走表。等待「开始」。
- **运行（Running）**：倒计时递减；菜单栏同步。
- **暂停（Paused）**：冻结当前剩余时间。
- **结束（Finished）**：归零，触发提醒（系统通知 + Dock 图标跳动），停在该阶段，等待用户「开始」推进到下一阶段的待开始态。

按钮对状态的作用：
- 开始/暂停：Ready/Paused → Running；Running → Paused
- 重置：任意 → 当前阶段 Ready
- 跳过：任意 → 下一阶段 Ready（不提醒）
- 阶段自然 Finished → 提醒 → 用户「开始」→ 下一阶段 Running

---

## 8. 数据与持久化

- **只持久化设置**（三个自定义时长）。存为本地配置文件。
- **不持久化计时进度**：应用退出后计时不保留，重开从第一个专注阶段的 Ready 态开始。

## 9. v1 范围清单

**包含**
- [x] 菜单栏常驻倒计时（甜点，单槽位图标⇄文本）+ 双击唤出主窗口 + 右键菜单
- [x] 主窗口（纯数字极简，浅/深双主题默认浅色）
- [x] 专注/短休/大休轮回，4 轮一大休
- [x] 手动推进 + 系统通知 + Dock 图标跳动
- [x] 开始 / 暂停 / 重置 / 跳过
- [x] 自定义三个时长（设置）
- [x] 关闭主窗口隐藏到菜单栏，菜单栏菜单可退出
- [x] 浅/深双主题（默认浅色，设置内切换，持久化）

**有意不做**（见上文「产品哲学」）：任务管理 / 统计报表 / 云同步 / 桌面浮窗。

## 11. 实现现状（原生 Swift）

> 本节为历史结构文档，技术栈已于 2026-06-10 从 Avalonia 迁移为原生 Swift（SwiftUI + AppKit），下列能力均已落地。当前实现细节以 [CLAUDE.md](../CLAUDE.md) 与 [swift 原生重写设计](2026-06-10-swift原生重写-design.md) 为准。

- **菜单栏动态文本**：原生 `NSStatusItem` 单槽位，图标⇄倒计时文本切换。
- **原生通知**：`UNUserNotificationCenter`（Xcode/xcodebuild 构建的 `.app` 自带 bundle 身份，直接可用）。
- **Dock 图标跳动**：阶段结束 `requestUserAttention(.criticalRequest)`，唤窗即撤销。
